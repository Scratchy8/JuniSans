# JuniSans

JuniSans is a revival of superellipse font Samsung Imagination Modern. It includes an upright roman style and a companion italic style, and also a bold style.

![Banner](Banner%20for%20JuniSans.png)

## Font Features

### Upright Style
* Designed around mathematical superellipse/squircle curves.
* Horizontal and vertical terminals.

### Italics
* 7-degree slanted **SPECIFICALLY**.
* Some structural changes to lowercase glyphs (`a`, and `f`).
* Extrema nodes adjusted to the slanted axis boundaries.
